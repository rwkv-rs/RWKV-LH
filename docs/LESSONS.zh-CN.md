# 当前工程与数据原则

本文只保留仍适用的判断原则。架构见[职责与协议](ARCHITECTURE.zh-CN.md)，最新结果、未解决问题和下一步只在[当前交接](HANDOFF.zh-CN.md)维护。文档不追加逐轮日志；历史文档查 Git，原始实验记录按本地证据路径复核。

- **先看完整交付。** 先报告 Strict、completed、实际 mutation 和终止原因，再报告角色格式、参数、loss 和 token。页面可打开、功能检查通过与 Agent 完成分别计量；预算耗尽不能记为完成。
- **逐次定位最早错误。** 核对模型当时所见完整输入、工具 schema、原始输出、实际回执和下一次输入。首次错误、检测位置、恢复与持续停滞分开记录；生成正文内重复和跨调用重复分开统计。
- **保留模型的决策责任。** Controller 校验权限、身份、证据和完成门，不选业务方向、不补模型缺少的参数、不把 reject 改成 accept、不改写 Final。强模型诊断同样需要真实执行验证。
- **格式与行为分别验收。** 合法参数仍可能指向错误 ID、重复已知读取、虚报文件或包含错误程序。输出截断单列为未测量，不能计入完整参数成功率；原始输出和归一化结果分别保存。
- **约束必须到达实际生成边界。** 从当前唯一工具定义派生 decoder，核对 Native 请求、服务源码/权重身份、生成回执与 checkpoint；独立检查原始 token 是否被 grammar 允许。输入预填充和已知 token 重建不套输出 grammar。所有新 RWKV 模型实验都开启约束。
- **严格模式要有反例测试。** API 接受 strict 或返回正确样例不证明服务强制 schema；保存原 wire、完整 SSE 和 tool_calls，用冲突 required/enum 的负控验证。参数、角色、权限与完成门仍独立校验。 先按官方文档核对每层object、必填字段、endpoint与thinking，再用独立直连探针区分客户端形状缺陷和服务返回违例；不能把未验证的兼容路径留成未来回退。
- **输入共享须可还原。** 只共享完整且逐字相同的文字，保留原位置、操作和回执身份。实际 token 不省就保留原展示；单次输入去重与跨次证据投递分别验证，输入缩短不自动证明任务收益。
- **State 生命周期必须闭合。** 核对真实 create、generate、commit/rollback、release 回执；清理前持久化已知生成。拒绝从干净 anchor 继续；未知 rollback 不释放父 State。假客户端不得提供服务没有的证明字段。
- **预留不等于发送。** 分别统计账本预留、generation_started、原始 HTTP、提供方返回和服务 journal。本地未发送失败与已发送 UNKNOWN 分开取证；后者不自动重试。
- **检查需要区分坏实现。** 检查的隔离环境、可访问接口和用户义务来自当前合同。实现未通过忠实检查不代表检查有错；独立审查和真正执行均保留，语法有效不等于行为覆盖。
- **训练来源与纠正目标各自取证。** 从真实生产边界抽取完整输入 token、State、模型、协议和工作区。原输出与纠正目标分开，执行正例需要实际工具回执，编辑需要公开检查失败→通过；作者自审不替代独立复核。
- **先审覆盖，再增加数量。** 同一任务族、重试和衍生副本不能扩大独立来源数；按任务族隔离固定回归，核对近重复与泄漏。开发题不改称真实用户任务；owner 单独授权其生产执行 trace 用于纠错时，保留原来源并重新过完整准入。接口探针、私有验收和参考实现不转为角色训练标签。
- **对比条件在运行前冻结。** 固定源码、模型、State、题集、预算、评分和分母；失败与未运行项如实保留。工程门通过、角色分数提高或一次运行改善不能替代新受控 Agent 验收。
- **后台验证环境要一致。** 并发 pytest 使用独立 basetemp，不能互相清理活动数据库和快照。显式固定 umask，文件权限是快照身份的一部分；不通过关闭校验解决环境差异。复用回归必须核对完整文件集合和逐文件 SHA。
- **只读审计也要锁。** 先取共享锁再以 immutable SQLite 读取，拒绝活动写者、缺锁和未 checkpoint WAL。一次租约内可共用内部验证的事件链，不能信任外部缓存或跳过后部证据。
- **存储与发布保持边界。** State 留在 8222，NAS 只存原始权重。服务器只接收本地冻结源码和清单，禁止 Git。GitHub 只发布维护源码、文档和构建配置；新分支也须核对待上传祖先，不能只检查最终目录树。
- **工作树只保留当前实现。** 每角色只有当前协议和唯一输入构造，不保留旧执行入口或兼容壳。旧 State 不经兼容核验不得复用；历史实现从 Git 查询。
