# Trace 前置：RWKV 离线输入顺序诊断建议

2026-09-13。原建议保留；owner后续授权的三条验证已在 `data/experiments/RWKV_THREE_TRACKS_DIAGNOSTIC_R1_20260913/` 独立冻结。T定义为RWKV可见分析笔记，不冒充内部推理轨迹。不接入生产、不训练、不新建数据集版本，不修改旧测试反馈基线。

## 原文核对

[Trace as State: Reasoning Traces as Conditional States for Long-Context Transformers](https://arxiv.org/html/2609.02702)，Xu Zou、Jie Tang，2026-09-02，arXiv:2609.02702v1。§4.1–4.3：DeepSeek V4 Pro Preview 在 GraphWalks Parents 的首遍/后置/前置准确率为29.2%/43.0%/81.8%。主实验复用五次首遍轨迹；前后置使用同一T，问题均放末尾。其重读对照为[x,q,x,q]。论文未验证RWKV或交互式Agent，并明确额外推理成本及轨迹可能错误的限制。

## 对本项目的价值与边界

待验证的假设：先看到任务相关线索，再逐段读取原文，可能让RWKV保留更相关的来源、对象与关系。不是“多想一遍必然更好”。本仓库已有来源顺序敏感证据，见 `RWKV_SOURCE_ATTRIBUTION_CONTROL_R1_20260913`；尚未证明长上下文容量不足或State传递错误是根因。

第一优先级是需求与实际实现的区分，以及数字的对象、分子分母、比较关系。第二优先级是从原入口检查新增helper是否真正生效；必须以实际入口的行为测试判定，不能只比较回答。

T是模型生成、可能出错的外部文字，不是WKV State序列化，也不是来源证据。前置错误线索可能强化错误；不能由程序或强模型挑出正确事实、改好T后再归功于RWKV。

## 建议的最小对照

先复用已开放开发实验的原始材料、任务及逐事实验收，不读confirmation或私有holdout。仅短材料能回答输入顺序问题，不能据此命名“长上下文问题已解决”。后续真正长度对照须登记各层实际token数，在当前模型上下文与输出预算内保留完整材料；不凭空填充或擅建数据集。

| 组 | 数据块顺序（x为原文，q为任务） | 目的 |
|---|---|---|
| 原始 | x → q | 当前输入基线 |
| 单纯重读 | x → q → x → q | 原文重复本身的收益 |
| 后置T | x → T → q | 同一T在原文之后 |
| 前置T | T → x → q | 同一T在原文之前 |

这些是输入中的数据块，不是另建角色协议。各组均须经过现有唯一输入构造函数和生产协议；固定公共说明、工具菜单及包装，不允许Harness补写事实或答案。诊断可使用模型可公开输出的核对笔记作为T，但若接口没有单独暴露推理轨迹，必须标为“笔记代理实验”，不能冒充论文原样复现或隐藏思维过程。第一阶段由RWKV生成T，不加入强模型混淆能力归属。

最小起点为每题一次T生成、同一T供两个位置组各重复两次；不按答案正确性挑选T，不在组间修正。T失败、空输出、超预算均保留并计入方法失败，不能只选有用T。具体任务数、T输出额度、总调用/token/时间预算尚未冻结，实际运行前须登记；此文不是运行登记。

所有组从相同模型/profile的独立起始State重建完整输入。不能给已经编码原文的State“前插”T，也不能让前置从zero开始、后置从首遍末State继续，以免把顺序与State历史混在一起。精确保存每组输入token、State身份与父子关系；T、x、q各自SHA应一致，前后置仅改变块顺序。若超上下文，两组同时按预登记处理，不静默截断。

## 评分与决策

冻结对象/原值/关系/来源对应的关键事实，区分核心错误、重要遗漏与一般细节；不逐字匹配。原文中的需求不算已实现，建议测试不算本轮已运行，公开测试通过不等于整个项目合格。

报告任务合格率、部分满足、实质事实错误、无交付；逐题比较前置相对后置改善和恶化，尤其记录T首遍错误被纠正或放大的情况。保留旧结果，不重新包装成训练收益。固定小组两遍全过仅支持该组内表现，不证明普遍稳定；存在改善时还需在未用于调方案的获准开发材料上复核。

成本按完整方法计入T生成、全文重放、失败及重试；共享T在实验总账去重，但每个方法部署成本分别包含生成T的费用。记录精确输入/输出token与端到端时间，不能只报告第二遍输出。RWKV独立任务可隔离并发，但服务实际吞吐收益需另测，不能把客户端并发当GPU加速。

优先完成当前真实测试反馈实验，再冻结这一离线对照。如果前置优于后置且超过重复波动，支持进一步研究输入组织；若两者相近而均优于原始，优先解释为额外计算或重复信息收益；若错误放大，则保留负结果，不给生产增加固定“先分析再重读”的补偿流程。

## Owner修订与本轮执行边界

输入位置实验不能直接决定改输入还是训练。T的生成方式、原始质量、样本长度、重复波动与成本都限制结论；其他任务的覆盖及跨阶段根因证据仍必需。

强模型协助和完整独立任务并发是并列验证线，不以多文件稳定或位置组通过为前提。本轮使用一次strong建议、同一旧失败父State的两次隔离续接；没有无建议重试对照，不能把全部变化归因于建议。并发使用现有生产调度入口，两个完整只读任务各自workspace/State，串行与并发各两遍；共享文件修改与集成不在其结论范围。

为避免不同运行负载污染串行/并发时延，三条线在本轮的服务器调度上分开运行；这是测量隔离，不是能力阶段的前置通关关系。冻结登记含完整T指令、输入块布局、模型/源码/父State身份、任务与评分、输出和调用预算、失败保留规则。
