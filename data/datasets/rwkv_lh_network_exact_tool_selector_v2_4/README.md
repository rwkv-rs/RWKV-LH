# RWKV-LH Network Exact-Tool Selector v2.4

Frozen 25-class operation-intent contract dataset for the independent 2.9B Hidden+MLP Selector. It contains 7500 semantic families with 240/30/30 train/dev/test rows per class. Labels are pre-registered operation contracts, not model-generated labels. The old v1 coverage collection plan is not used as training data.
