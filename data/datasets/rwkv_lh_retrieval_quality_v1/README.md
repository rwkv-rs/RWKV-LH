# RWKV-LH retrieval quality v1

Nine preregistered public-network cases measure source relevance and evidence
usability rather than connectivity alone. They cover exact URL fetch, English and
Chinese discovery, GitHub, PyPI, Crossref, and weather. Expected domains and
literal terms identify stable source families; no time-varying answer value is
frozen. The dataset was manually registered on 2026-08-29 before the one-shot run.
