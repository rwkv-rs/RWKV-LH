Input an integer `n`. Output the expression for 2^-n in the format x.xxxE-y. There are multiple test cases in the input.

## Input/Output Example

### Input Example #1

```
8271
6000
1
```

### Output Example #1

```
2^-8271 = 1.517E-2490
2^-6000 = 6.607E-1807
2^-1 = 5.000E-1
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
