Input any character and determine if its ASCII value is odd. If it is, output `YES`; otherwise, output `NO`.

For example, the ASCII value of character `A` is `65`, so output `YES`. If the input character is `B` (ASCII value is `66`), output `NO`.

## Input Format

Input a single character.

## Output Format

If the ASCII value of the character is odd, output `YES`; otherwise, output `NO`.

## Sample Input and Output

### Sample Input #1

```
A
```

### Sample Output #1

```
YES
```

### Sample Input #2

```
B
```

### Sample Output #2

```
NO
```

The input will be given via stdin and the output should be printed to stdout by your code.
