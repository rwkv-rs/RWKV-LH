A hospital is conducting a study to determine if a certain disease is related to age. To do this, they are organizing past diagnostic records and calculating the proportion of patients in the four age groups: 0-18, 19-35, 36-60, and 61 and above, relative to the total number of patients.

## Input Format

The input consists of 2 lines.

The first line contains an integer \( N \) (\( 0 < N \leq 100 \)), representing the total number of patients.

The second line contains \( N \) integers, each representing the age of a patient at the time of their visit.

## Output Format

The output consists of 4 lines.

The first line contains a percentage, rounded to two decimal places, representing the proportion of patients aged 0-18 relative to the total number of patients.

The second line contains a percentage, rounded to two decimal places, representing the proportion of patients aged 19-35 relative to the total number of patients.

The third line contains a percentage, rounded to two decimal places, representing the proportion of patients aged 36-60 relative to the total number of patients.

The fourth line contains a percentage, rounded to two decimal places, representing the proportion of patients aged 61 and above relative to the total number of patients.

## Sample Input and Output

### Input Sample #1

```
10
1 11 21 31 41 51 61 71 81 91
```

### Output Sample #1

```
20.00%
20.00%
20.00%
40.00%
```

### Input Sample #2

```
12
10 19 86 94 58 57 34 19 88 69 5 13
```

### Output Sample #2

```
25.00%
25.00%
16.67%
33.33%
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
