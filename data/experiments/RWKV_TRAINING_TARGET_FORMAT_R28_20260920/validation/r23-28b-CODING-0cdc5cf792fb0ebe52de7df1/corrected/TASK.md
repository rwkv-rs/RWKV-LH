Company $G$ has $n$ warehouses arranged in a circular pattern along a railway line, with each warehouse storing a different amount of goods. The task is to determine the minimum amount of goods to be moved so that the inventory in all $n$ warehouses becomes equal. Goods can only be moved between adjacent warehouses.

## Input Format

The first line contains a positive integer $n$, representing the number of warehouses.

The second line contains $n$ positive integers, representing the inventory amounts of the $n$ warehouses.

## Output Format

Output the minimum amount of goods to be moved.

## Sample Input and Output

### Input Sample #1

```
5
17 9 14 16 4
```

### Output Sample #1

```
11
```

## Notes

$1 \leq n \leq 100$.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
