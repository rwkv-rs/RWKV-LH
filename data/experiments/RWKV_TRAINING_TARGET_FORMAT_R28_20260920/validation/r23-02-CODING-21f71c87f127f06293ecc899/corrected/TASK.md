Given an integer $n(1\le n<2^{31})$, find at least two positive integers whose least common multiple (LCM) is $n$, such that the sum of these integers is minimized. Output the minimum sum.

There can be multiple test cases and the input ends with a $0$.

Thanks to @_pfy_ for the translation.

## Input and Output Example

### Input Example #1

```
12
10
5
0
```

### Output Example #1

```
Case 1: 7
Case 2: 7
Case 3: 6
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
