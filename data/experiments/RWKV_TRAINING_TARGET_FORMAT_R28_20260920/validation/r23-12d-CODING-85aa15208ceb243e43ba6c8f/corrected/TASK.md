Windy's birthday has arrived, and to celebrate, his friends have bought him a rectangular cake with sides of length $X$ and $Y$.

Now, including Windy, there are $N$ people to share this large cake, and each person must receive an equal area of cake.

Windy is the one cutting the cake. Each cut can only be parallel to one side of the cake (either side), and must divide the cake into two pieces.

To cut the cake into $N$ pieces, Windy must make $N-1$ cuts.

To make each piece of cake look aesthetically pleasing, we want to minimize the maximum ratio of the longer side to the shorter side among the $N$ pieces.

Can you help Windy find this ratio?

## Input Format

A single line containing three integers $X, Y, N$.

## Output Format

A single floating-point number, rounded to six decimal places.

## Sample Input and Output

### Sample Input #1

```
5 5 5
```

### Sample Output #1

```
1.800000
```

## Notes

For $100\%$ of the data, it is guaranteed that $1 \le X, Y \le 10^4$ and $1 \le N \le 10$.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
