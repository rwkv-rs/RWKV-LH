Given a series of words composed entirely of uppercase letters, identify words that meet the following conditions:

1. They contain two palindromic strings, `str1` and `str2`, each with a length of at least 3.
2. `str1` and `str2` must not contain each other, nor can they be identical.

Output each word that satisfies these conditions, one per line, in the order they appear.

## Input and Output Examples

### Input Example #1

```
MOEILIJKHEDEN INVOER
VERNEDEREN
AMUMA AMAMA MUMMUM
AMATRAMA AAAA
ABATRABAR
DUMMY
WORDS
```

### Output Example #1

```
MOEILIJKHEDEN
VERNEDEREN
AMAMA
MUMMUM
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
