- For a positive integer $ n \;(1 \le n \le 10^8)$, determine whether it can be expressed as the sum of two prime numbers.

- If it can be expressed as the sum of two primes $ p_1, p_2\;(p_1<p_2)$, output `n is the sum of p1 and p2.` with the smallest possible value of $p_2-p_1$.
- If it cannot be expressed as the sum of two primes, output `n is not the sum of two primes!`.
- Multiple test cases are provided in the input.

## Input and Output Example

### Sample Input #1

```
11
12
```

### Sample Output #1

```
11 is not the sum of two primes!
12 is the sum of 5 and 7.
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
