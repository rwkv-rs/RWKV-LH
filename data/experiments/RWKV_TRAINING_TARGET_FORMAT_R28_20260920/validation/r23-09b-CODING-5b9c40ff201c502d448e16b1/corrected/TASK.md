Given two line segments in space, find their minimum distance. The first line of input contains the number of test cases $T$. Each subsequent pair of lines represents a set of data, containing six integers $x1, y1, z1, x2, y2, z2$ (endpoint coordinates), each with an absolute value not exceeding $20$. Output two coprime integers $l$ and $m$, such that $m > 0$ and $l ÷ m$ is the square of the desired distance.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
