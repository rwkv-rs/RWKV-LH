Determine the number of prime numbers in the range from $1$ to $N$.

## Input Format

A single line containing an integer $N$.

## Output Format

A single line containing an integer, representing the count of prime numbers.

## Sample Input and Output

### Input Sample #1

```
10
```

### Output Sample #1

```
4
```

## Notes

For $40\%$ of the test cases, $1 \le N \le 10^6$.

For $80\%$ of the test cases, $1 \le N \le 10^7$.

For $100\%$ of the test cases, $1 \le N \le 10^8$.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
