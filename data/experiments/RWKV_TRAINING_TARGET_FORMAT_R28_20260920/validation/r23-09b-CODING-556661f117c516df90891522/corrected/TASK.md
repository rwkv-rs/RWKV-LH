For an integer $n$ greater than $1$, the Farey sequence $F_n$ is defined as a set of fractions $\{a/b\}$, where $0 < a < b \leq n$ and $\gcd(a, b) = 1.$

For example, the first few terms are:

$F_2 = \{1/2\}$

$F_3 = \{1/3, 1/2, 2/3\}$

$F_4 = \{1/4, 1/3, 1/2, 2/3, 3/4\}$

$F_5 = \{1/5, 1/4, 1/3, 2/5, 1/2, 3/5, 2/3, 3/4, 4/5\}$

For each given $n$, find the number of fractions in $F_n$.

## Input and Output Format
### Input Format:
Each line contains a number $n$. The input ends with a $0$. There can be up to 20000 lines.

### Output Format:
Each line should contain a number, representing the number of fractions in $F_n$.

## Input and Output Example

### Input Example #1

```
1
4
0
```

### Output Example #1

```
0
5
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
