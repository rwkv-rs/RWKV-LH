# [BUG] ValueError crash when logging in Cython or atexit context

## Crash Description
The logging system crashes with a ValueError when attempting to log messages in certain execution environments where the call stack depth is insufficient. This occurs when the logger tries to retrieve stack frame information for logging purposes but cannot access the required frame depth.

## Trigger Condition
- **Input/State**: Logging operations performed in environments with limited stack frame availability, such as:
  - Code compiled with Cython
  - Functions registered with `atexit.register()` for execution at program shutdown
- **Environment**: Cython-compiled executables or Python scripts using atexit handlers

## Error Type
ValueError: call stack is not deep enough

## Steps to Reproduce
1. For Cython scenario:
   - Write a Python script using loguru for logging
   - Compile the script to an executable using Cython
   - Run the compiled executable
   - Observe crash when logging is attempted

2. For atexit scenario:
   - Import loguru logger and atexit module
   - Register a logger method with atexit.register()
   - Allow the program to exit normally
   - Observe crash during atexit cleanup when the registered logger method is called

## Expected Behavior
The logging system should handle environments where stack frame information is unavailable gracefully, allowing logging to continue without crashing the program.
