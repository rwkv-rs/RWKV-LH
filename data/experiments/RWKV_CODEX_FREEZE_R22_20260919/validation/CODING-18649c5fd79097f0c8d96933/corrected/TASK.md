This problem contains multiple sets of data. For each set, you are given a list of strings composed only of '0's and '1's, ending with the character "9". If any string in the set is a prefix of another string, output "Set &case is not immediately decodable". Otherwise, output "Set &case is immediately decodable". Each output should be followed by a newline. The case number starts at 1.

## Input and Output Samples

### Sample Input #1

```
01
10
0010
0000
9
01
10
010
0000
9
```

### Sample Output #1

```
Set 1 is immediately decodable
Set 2 is not immediately decodable
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
