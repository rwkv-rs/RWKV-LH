### Background
Huatuo is a famous doctor. He uses identical bottles to store medicine, and there are different types of medicine. He places the medicine into bottles and strings these bottles together.

However, there is a crucial issue. When Huatuo arrives at a patient's home, he takes out the chain of bottles from his bag, but he does not know which bottle contains which type of medicine. Nevertheless, he remembers the order of the bottles on the chain.

Huatuo has his own solution. When he needs to carry two types of medicine, say medicine A and B, he will put A in one bottle and B in two bottles. He then chains the bottles in the order -B-A-B-. This way, when he reaches the patient's home, he knows that the middle bottle contains medicine A and the side bottles contain medicine B.

Now, you need to help Huatuo calculate the number of bottles required if he wants to carry N types of medicine.

### Input
The first line of the input gives the number of test cases, $T$ (1 ≤ $T$ ≤ 100). The following $T$ lines each contain an integer $N$ (1 ≤ $N$ ≤ 100), which represents the number of types of medicine.

### Output
For each test case, output one line in the format: `Case #x: y`, where $x$ is the current test case number (starting from 1), and $y$ is the minimum number of bottles Huatuo needs.

## Sample Input

### Sample Input #1

```
1
2
```

### Sample Output #1

```
Case #1: 3
```
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
