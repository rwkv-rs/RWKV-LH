Given a circuit of $n-1$ points on a plane, where the $n$th vertex is the same as the 1st vertex, determine how many regions it divides the entire plane into (including the enclosed internal region and the infinite external region).

## Input Format
This problem contains multiple datasets (up to 25).

For each dataset, the first line contains an integer $n$.

The second line contains $2n$ integers, which are the coordinates $x_i, y_i$ representing the $n$ points. The data guarantees that $x_n=x_1, y_n=y_1$.

$n=0$ indicates the end of the data.

## Output Format
For each dataset, output one line in the following format, where $x$ represents the dataset number, and $w$ is the answer.

**Case** $x$**: There are **$w$** pieces.**

## Constraints
Number of datasets $\leqslant 25$

$4\leqslant n\leqslant 300$

$-300\leqslant x_i,y_i\leqslant 300$
