A certain company has mastered the technology to produce an element called X. In the coming months, they will produce some X elements for sale and aim to achieve maximum profit. They have provided some data and hope you can help calculate the maximum profit.

The first line of input contains an integer T, representing the number of data sets. 
For each data set, the first line contains two integers, M and I, which represent the number of months to consider and the cost to store one unit of X element for a month. 
The following M lines each contain 5 integers representing the monthly data: the production cost per unit of X element, the maximum production capacity of X element, the selling price per unit of X element, the maximum sales capacity of X element, and the shelf life of the X element produced that month (e.g., if the X element is produced in January and has a shelf life of 3 months, it must be sold by the end of April; otherwise, it expires and becomes worthless).

Output the maximum profit, following the format of the sample output.

## Example Input/Output

### Example Input #1

```
1
2 2
2 10 3 20 2
10 100 7 5 2
```

### Example Output #1

```
Case 1: 20
```
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
