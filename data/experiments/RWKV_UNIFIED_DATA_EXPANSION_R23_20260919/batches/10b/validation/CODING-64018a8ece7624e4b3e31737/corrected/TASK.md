Xiao Ming and Xiao Hong often play a game of strategy. Given a chessboard of size $n \times n$, a stone is placed at the top-left corner of the board. They take turns moving the stone. In each turn, a player can move the stone one cell up, down, left, or right, with the condition that the cell it moves to has not been visited before. The player who cannot move the stone loses.

If Xiao Ming moves first and both players play optimally, who will win the game?

## Input Format

The input file contains multiple sets of data.

The first line of input contains an integer $n$, representing the size of the chessboard.

When $n$ is $0$, it indicates the end of the input.

## Output Format

For each set of data, if Xiao Ming can win, output `Alice`; otherwise, output `Bob`. Each answer should be on a separate line.

## Sample Input and Output

### Sample Input #1

```
2
0
```

### Sample Output #1

```
Alice
```

## Notes/Hints

For $20\%$ of the data, $1 \le n \le 10$;

For $40\%$ of the data, $1 \le n \le 1000$;

For $100\%$ of the data, $1 \le n \le 10000$.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
