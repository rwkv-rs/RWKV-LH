- Given an integer $k$, find the smallest integer $n$ such that there exists an expression:
$$\texttt ?\ 1\ \texttt ?\ 2\ \texttt ?\cdots\texttt ?\ n=k$$
- In this expression, each $\texttt ?$ can be replaced with either $\texttt +$ or $\texttt -$.
- **Multiple test cases**: The first line of input contains the number of test cases. For each test case, an integer $k$ is provided, where $0 \le |k| \le 10^9$.
- $n$ must satisfy $1 \le n$.

## Input and Output Example

### Input Example #1

```
2
12
-3646397
```

### Output Example #1

```
7
2701
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
