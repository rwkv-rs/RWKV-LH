Stan and Ollie are playing a game. The rules of this game are quite interesting: given an integer \( n \), you start multiplying from 1, by any number between 2 and 9. The first person to obtain a number greater than or equal to \( n \) wins. Stan goes first, followed by Ollie. So, given a number \( n \), if both Stan and Ollie are smart enough to always use the optimal strategy, who will win?

### Input Format

Multiple sets of data, with each line containing a number \( n \).

### Output Format

For each line, output who will win. If Stan wins, output "Stan wins." Otherwise, output "Ollie wins." (Note the period at the end.)

### Sample Input #1

```
162
17
34012226
```

### Sample Output #1

```
Stan wins.
Ollie wins.
Stan wins.
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
