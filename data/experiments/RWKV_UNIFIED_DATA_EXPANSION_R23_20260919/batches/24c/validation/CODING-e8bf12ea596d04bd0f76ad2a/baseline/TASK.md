Find two integers \( a, b \) such that \( 1 \le a, b \le n \) and maximize \( (a \ \mathrm{or}\ b) + (a \ \mathrm{xor}\ b) \). Output this maximum value.

## Input Format

A single positive integer \( n \).

## Output Format

A single positive integer, which is the answer.

## Sample Input and Output

### Sample Input #1

```
5
```

### Sample Output #1

```
14
```

## Notes

Sample explanation: \( (5 \ \mathrm{or}\ 2) + (5 \ \mathrm{xor}\ 2) = 14 \).

For 80% of the test cases, \( n \le 1000 \).

For 100% of the test cases, \( 2 \le n \le 10^{18} \).

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
