You are given $ N $ points on a plane where both the $ x $ and $ y $ coordinates are integers.

From these points, how many ways are there to choose $ 4 $ points such that no $ 3 $ of them are collinear? Output the answer modulo $ 1,000,000,007 $.

The input is given from the standard input in the following format:

> $ N $ $ x_1 $ $ y_1 $ : $ x_N $ $ y_N $

- The first line contains the number of points $ N $.
- The next $ N $ lines contain the $ x $ and $ y $ coordinates of the $ i $-th point, separated by a space.
- $ 4 \leq N \leq 10^4 $
- $ 0 \leq x_i \leq 99\ (1 \leq i \leq N) $
- $ 0 \leq y_i \leq 99\ (1 \leq i \leq N) $
- If $ i \neq j $, then $ x_i \neq x_j $ or $ y_i \neq y_j $

If you correctly solve the input with $ 4 $ points ($ N = 4 $), you will be awarded $ 4 $ points out of a possible $ 100 $.

If you correctly solve the input with $ N \leq 100 $, you will be awarded an additional $ 16 $ points out of a possible $ 100 $.

If you correctly solve the input with $ N \leq 1000 $, you will be awarded an additional $ 30 $ points out of a possible $ 100 $.

Output the number of ways to choose $ 4 $ points such that no $ 3 $ of them are collinear, modulo $ 1,000,000,007 $, in one line.

Note that a newline is required at the end of the line.
