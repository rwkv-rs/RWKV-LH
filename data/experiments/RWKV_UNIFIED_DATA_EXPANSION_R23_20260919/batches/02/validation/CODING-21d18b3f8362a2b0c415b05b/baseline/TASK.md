## Problem Description

There are $n$ sticks. Xiao Y wants to select 4 of them to form an equilateral triangle. How many ways are there to do this?

The answer should be taken modulo $10^9+7$.

## Input Format

The first line contains an integer $n$.

The next $n$ lines each contain one integer, where the $i$-th integer $a_i$ represents the length of the $i$-th stick.

## Output Format

Output a single integer representing the answer.

## Sample Input and Output

### Sample Input #1

```
4
1
1
2
2
```

### Sample Output #1

```
1
```

## Notes

### Data Size and Constraints

- For $30\%$ of the data, $n \le 5 \times 10^3$.
- For $100\%$ of the data, $1 \leq n \le 10^5$, and $1 \le a_i \le 5 \times 10^3$.
