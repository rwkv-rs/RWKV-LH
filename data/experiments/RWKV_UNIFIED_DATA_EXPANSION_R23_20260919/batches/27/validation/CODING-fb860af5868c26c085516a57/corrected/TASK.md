You are given two purchasing options for buying items: spend $c_1$ dollars to buy $n_1$ items, or spend $c_2$ dollars to buy $n_2$ items. You can use each option an unlimited number of times. Determine the minimum amount of dollars needed to purchase exactly $n$ items, or output $\texttt{failed}$ if it is impossible to buy exactly $n$ items.

## Input and Output Example

### Input Example #1

```
43
1 3
2 4
40
5 9
5 12
0
```

### Output Example #1

```
13 1
failed
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
