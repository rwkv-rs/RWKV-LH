### Problem Summary
For each given positive integer $N$ on a separate line, output the smallest positive integer $e$ such that $2^e$ begins with $N$, and the number of digits in $N$ is less than half the number of digits in $2^e$.

If no such $e$ exists, output the line ```no power of 2```

### Constraints

$0 \le N \le 2^{32} - 1$

## Input and Output Samples

### Input Sample #1

```
1
2
10
```

### Output Sample #1

```
7
8
20
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
