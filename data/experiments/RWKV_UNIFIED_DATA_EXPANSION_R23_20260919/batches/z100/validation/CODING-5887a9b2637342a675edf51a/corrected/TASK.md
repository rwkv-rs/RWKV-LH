Problem Description:

Identify the counterfeit coin problem

You are given N coins, where N-1 are genuine coins and 1 is a counterfeit coin. The genuine coins all have the same weight, but the counterfeit coin differs in weight from the genuine coins. You have a balance scale without any weights. Can you determine the counterfeit coin in K weighings?

Input Format:

The first line contains the number of test cases T. The following T lines each contain two integers N and K, with 2≤N≤100 and 0≤K≤100.

Output Format:

For each pair (N, K), if it is possible to find the counterfeit coin, output a line “POSSIBLE”; if it is not possible, output a line “IMPOSSIBLE”.
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
