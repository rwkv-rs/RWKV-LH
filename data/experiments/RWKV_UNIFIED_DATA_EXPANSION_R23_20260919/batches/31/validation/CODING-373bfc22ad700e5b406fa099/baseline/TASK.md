On a certain planar land, there are N points. You can choose any four points from these to enclose the land, and naturally, you want the polygon formed by these four points to have the maximum area.

## Input Format

The first line contains a positive integer N. The next N lines each contain two numbers x and y, representing the x and y coordinates of the point.

## Output Format

The maximum area of the polygon, accurate to three decimal places.

## Sample Input and Output

### Input Sample #1

```
5
0 0
1 0
1 1
0 1
0.5 0.5
```

### Output Sample #1

```
1.000
```

## Notes

Data range: n <= 2000, |x|, |y| <= 100000

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
