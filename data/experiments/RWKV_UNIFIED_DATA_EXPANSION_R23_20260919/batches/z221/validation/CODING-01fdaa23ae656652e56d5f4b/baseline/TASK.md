Count the number of labeled directed acyclic graphs (DAGs) with $n$ vertices, where the graph is weakly connected (replacing all directed edges with undirected edges results in a connected graph). Output the result modulo $998244353$.

## Input Format

A single integer $T$.

## Output Format

Output $T$ lines. The $i$-th line ($1 \le i \le T$) should contain the answer for $n = i$.

## Sample Input and Output

### Input Sample #1

```
5
```

### Output Sample #1

```
1
2
18
446
26430
```

## Notes

The first point has $T = 2000$.

The second point has $T = 100000$.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
