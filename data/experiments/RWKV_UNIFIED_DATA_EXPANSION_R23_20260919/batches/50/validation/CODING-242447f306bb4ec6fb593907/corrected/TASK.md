You are given a $15\times15$ chessboard. A rook can attack all the squares in the same row and column. Determine the minimum number of rooks required to attack all the squares marked with '#'.

## Input and Output Example

### Input Example #1

```
...............
...............
...............
...............
...............
...............
...............
.......#.......
...............
...............
...............
...............
...............
...............
...............
END
```

### Output Example #1

```
1
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
