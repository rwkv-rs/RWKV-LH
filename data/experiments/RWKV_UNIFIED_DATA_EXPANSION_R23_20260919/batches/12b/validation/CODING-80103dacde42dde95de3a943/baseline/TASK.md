For resistors with resistances $r_1$ and $r_2$, the formula to calculate the resistance of their parallel connection is as follows:
$$R=\dfrac{1}{\dfrac{1}{r_1}+\dfrac{1}{r_2}}$$

Given real numbers $r_1$ and $r_2$, output the resistance of the parallel connection, rounded to two decimal places.

## Input Format

Two real numbers $r_1$ and $r_2$, separated by a space.

## Output Format

The resistance of the parallel connection, rounded to two decimal places.

## Sample Input and Output

### Sample Input #1

```
1 2
```

### Sample Output #1

```
0.67
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
