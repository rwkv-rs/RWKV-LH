Given $n$, determine how many factorials $0!, 1!, 2!, \ldots, n!$ have an even number of trailing zeroes.

Input Format:

A single line containing the number $n$ ($1 \leq n \leq 10^{18}$). The input ends when $-1$ is encountered (do not output an answer for $n = -1$).

Output Format:

For each input, output the corresponding answer on a new line.

## Input and Output Examples

### Input Example #1

```
2
3
10
100
1000
2000
3000
10000
100000
200000
-1
```

### Output Example #1

```
3
4
6
61
525
1050
1551
5050
50250
100126
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
