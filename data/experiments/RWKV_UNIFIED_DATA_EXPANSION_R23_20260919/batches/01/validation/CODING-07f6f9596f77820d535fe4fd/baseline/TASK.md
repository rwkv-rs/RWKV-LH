$lcm$ stands for the least common multiple. For a given number $n$, $MSLCM(n)$ represents the largest sum of numbers in a set whose $lcm$ is $n$.

## Input Format

Several sets of input data are given. Each set contains at most 200 numbers. Each line provides a number $n~(1 < n \le 20000000)$, and you need to calculate $\sum\limits_{i=2}^n MSLCM(i)$.

## Output Format

For each $n$, output $\sum\limits_{i=2}^n MSLCM(i)$.

## Sample Input

```
10
1000
0
```

## Sample Output

```
86
823080
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
