- In a grid that satisfies $|x| \le a$ and $|y| \le b$, there is a tree at every integer point except for the origin. The trees are point-sized but can block each other. Determine how many trees are visible from the origin.
- Output the ratio of visible trees to all trees with a precision of 7 decimal places.
- $a < 2000$, $b \le 2 \times 10^6$.

## Input and Output Example

### Input Example #1

```
3 2
0 0
```

### Output Example #1

```
0.7058824
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
