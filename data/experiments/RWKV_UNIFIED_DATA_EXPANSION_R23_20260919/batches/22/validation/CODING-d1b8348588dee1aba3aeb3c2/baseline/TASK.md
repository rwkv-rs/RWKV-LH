JSOI has assigned a task to ZYX, a team member, to develop a computer software called "Text Generator" for young children. The software is intended to replace the current GW Text Generator v6, which is used by the users.

The software is designed to randomly generate articles of a fixed length, where each character in the article is completely random. An article is considered readable if it contains at least one word that the users are familiar with (we say that article $s$ contains word $t$ if and only if word $t$ is a substring of article $s$). However, even with this criterion, the articles generated by GW Text Generator v6 are almost entirely unreadable. ZYX needs to determine the number of readable texts generated by GW Text Generator v6 to successfully obtain the v7 update. Can you help him?

The answer should be taken modulo $10^4 + 7$.

## Input Format

The first line contains two integers, representing the total number of words $n$ that the users know and the length $m$ of the generated article.

The following $n$ lines each contain a string $s_i$, representing a word that the users know.

## Output Format

Output a single integer, which is the result of the answer modulo $10^4 + 7$.

## Sample Input and Output

### Input Sample #1

```
2 2
A
B
```

### Output Sample #1

```
100
```

## Notes/Hints

### Data Size and Constraints

For all test cases, the following constraints apply:

- $1 \leq n \leq 60$, $1 \leq m \leq 100$.
- $1 \leq |s_i| \leq 100$, where $|s_i|$ denotes the length of string $s_i$.
- $s_i$ contains only uppercase English letters.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
