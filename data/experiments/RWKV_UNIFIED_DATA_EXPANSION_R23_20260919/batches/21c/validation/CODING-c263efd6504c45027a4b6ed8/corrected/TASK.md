Rita began collecting candles for each birthday starting from the age of $4$, while her brother Theo started from the age of $3$.

One day, Theo transferred a certain number of candles from his box to his sister's box. Given the age difference $D$, the number of candles currently in Rita's box $R$, and the number of candles currently in Theo's box $T$, determine how many candles Theo transferred.

There are multiple test cases.

## Input and Output Example

### Input Example #1

```
2
26
8
```

### Output Example #1

```
4
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
