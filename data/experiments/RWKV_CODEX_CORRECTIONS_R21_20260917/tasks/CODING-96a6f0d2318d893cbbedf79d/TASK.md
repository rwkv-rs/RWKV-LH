There are n objects (n≤128) and m characteristics (m≤11). Each object is represented by an m-digit binary string, indicating whether each characteristic is present or not. I have a specific object in mind (it is definitely one of these n objects), and you need to guess which one it is. Each time, you can ask about one characteristic, and I will tell you whether the object in my mind possesses this characteristic. Once you are certain of the answer, you can tell me the answer (providing the answer does not count as "asking"). If you adopt the optimal strategy, what is the minimum number of questions required to guarantee guessing the object? For example, given two objects: 1100 and 0110, asking about characteristic 1 or characteristic 3 ensures you guess correctly.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
