Initially, there is one red balloon. After each hour, one red balloon turns into 3 red balloons and one blue balloon, while one blue balloon turns into 4 blue balloons. As shown in the diagram, these are the situations after 0, 1, 2, and 3 hours. After k hours, how many red balloons are there from row A to B?

## Input and Output Samples

### Input Sample #1

```
3
0 1 1
3 1 8
3 3 7
```

### Output Sample #1

```
Case 1: 1
Case 2: 27
Case 3: 14
```

The input will be given via stdin and the output should be printed to stdout by your code.
