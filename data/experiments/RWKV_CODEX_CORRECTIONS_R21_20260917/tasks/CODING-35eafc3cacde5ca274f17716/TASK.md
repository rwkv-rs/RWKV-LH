Given the names and birthdates of $n$ individuals, determine who is the oldest and who is the youngest.

## Input Format
The first line contains an integer $n$, representing the number of people.  
The following $n$ lines each contain a string followed by three integers, which represent a person's name, birth day, birth month, and birth year, respectively.

## Output Format
Output two lines, each containing a string: the name of the oldest person on the first line and the name of the youngest person on the second line.

## Constraints
$1 \le n \le 100$, $1 \le \text{length of name} \le 15$

## Input and Output Example

### Input Example #1

```
5
Mickey 1 10 1991
Alice 30 12 1990
Tom 15 8 1993
Jerry 18 9 1990
Garfield 20 9 1990
```

### Output Example #1

```
Tom
Jerry
```
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
