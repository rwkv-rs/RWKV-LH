There is a password lock with `n` (where `n ≤ 1000`) digits. Each digit ranges from 0 to 9 and can rotate cyclically. You can rotate 1 to 3 adjacent digits at the same time, either up or down by one position (for example, 567890 -> 567901, where the last 3 digits rotate up). Given an initial state and a target state (each with a length of up to 1000), determine the minimum number of rotations required to reach the target state from the initial state.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
