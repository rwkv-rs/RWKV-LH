How many isomers of alkanes with $n$ carbon atoms are there (without considering stereoisomers)?

Hint: If you are unfamiliar with alkanes, you can consider this problem equivalent to finding the number of unlabeled, rooted trees with $n$ nodes where each node has a degree of at most 4.

## Input Format

A single integer $n$ representing the number of carbon atoms.

## Output Format

An integer representing the answer, modulo $998244353$.

## Sample Input and Output

### Input Sample #1

```
5
```

### Output Sample #1

```
3
```
