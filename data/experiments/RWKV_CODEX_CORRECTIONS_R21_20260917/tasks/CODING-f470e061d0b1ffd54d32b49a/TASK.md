Problem Summary:  
In a kingdom's forest, there are several trees, each with four input details: x-coordinate, y-coordinate, value \( v \), and the length of wood \( l \) that can be obtained if chopped down. The king wants to cut down some trees, use the wood from these cut trees to enclose the remaining trees, and at the same time, wants to minimize the total value of the cut trees. Find the optimal way to achieve this.  
\( N \leq 15 \)

## Input and Output Examples

### Input Example #1

```
6
0 0 8 3
1 4 3 2
2 1 7 1
4 1 2 3
3 5 4 6
2 3 9 8
3
3 0 10 2
5 5 20 25
7 -3 30 32
0
```

### Output Example #1

```
Forest 1
Cut these trees: 2 4 5
Extra wood: 3.16
Forest 2
Cut these trees: 2
Extra wood: 15.00
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
