Given an undirected graph $G$ with $n$ vertices and $m$ edges ($n \leq 30, m \leq 1000$). Each time, you randomly add a non-loop edge $(u, v)$ (duplicate edges may appear after adding). The probability of adding each edge is equal. Calculate the expected number of operations needed to make $G$ connected.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
