Suppose there are $n$ burgers in total ($n$ is an even number and $n \leq 100000$), consisting of $n/2$ ham burgers and $n/2$ cheese burgers.

$n$ children are seated in a row, each selecting a burger with equal probability. Interestingly, right after the third last child picks, the chef finds that the selection cannot proceed, because only two identical burgers are left.

The chef finds this amusing and wants to know the probability of this situation occurring.

Input Format
The first line contains an integer $t$, representing the number of test cases.

For each test case, an integer $n$ is given, as described above.

Output Format
Output $t$ lines, each containing the answer for the corresponding test case.

## Input and Output Samples

### Input Sample #1

```
3
6
10
256
```

### Output Sample #1

```
0.6250
0.7266
0.9500
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
