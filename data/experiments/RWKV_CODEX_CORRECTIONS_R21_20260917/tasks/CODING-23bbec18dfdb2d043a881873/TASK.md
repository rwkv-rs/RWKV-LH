A kinship string is defined as follows: For a given string \( s \), the ASCII value of the first character plus the ASCII value of the second character yields the first kinship character; the ASCII value of the second character plus the ASCII value of the third character yields the second kinship character; and so on. Note: The last character of the kinship string is obtained by adding the ASCII value of the last character of \( s \) to the ASCII value of the first character of \( s \).

## Input Format

Input consists of a single line, containing a string with a length greater than or equal to 2 and less than or equal to 100.

## Output Format

Output a single line, which is the transformed kinship string. The input guarantees that the transformed string will be a single line.

## Sample Input and Output

### Sample Input #1

```
1234
```

### Sample Output #1

```
cege
```

The input will be given via stdin and the output should be printed to stdout by your code.
