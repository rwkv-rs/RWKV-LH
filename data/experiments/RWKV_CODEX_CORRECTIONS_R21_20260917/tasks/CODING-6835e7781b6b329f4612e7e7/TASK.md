Given two dice, determine if they are equivalent. Each die is represented by 6 letters, as shown in the first illustration.

For example, "rbgggr" and "rggbgr" represent the two dice in the illustrations below. These two dice are equivalent because rotating the die in Figure 1 by 90° around the vertical axis results in the die shown in Figure 2.

### Input Format

A total of 12 letters, with the first 6 letters representing the six faces of the first die and the last 6 letters representing the six faces of the second die.

### Output Format

A Boolean value. If the two dice are equivalent, output `TRUE`; otherwise, output `FALSE`.

## Input and Output Examples

### Input Example #1

```
rbgggrrggbgr
rrrbbbrrbbbr
rbgrbgrrrrrg
```

### Output Example #1

```
TRUE
FALSE
FALSE
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
