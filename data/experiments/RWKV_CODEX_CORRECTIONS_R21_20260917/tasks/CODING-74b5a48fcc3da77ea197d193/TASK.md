Little A is working on a model. He wants to know how many square meters of material are needed to make the model shown in the figure below? The values of $a, b, c$ are given in the input, and the units of $a, b, c$ are **centimeters**. The value of pi is $\pi = 3.1415926535$.

![Image](https://cdn.luogu.com.cn/upload/image_hosting/qis1zjmj.png)

## Input Format

Three positive integers $a, b, c$ separated by spaces.

## Output Format

Output a single line containing a floating-point number, rounded to three decimal places, indicating the total square meters of material needed.

## Sample Input and Output

### Sample Input #1

```
30 40 50
```

### Sample Output #1

```
0.666
```

## Notes

The data guarantees that $1 \leq a, b, c \leq 100$.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
