**Background**: You are going to a store to buy N bottles of cola.

**Problem Description**: Every time you finish a bottle of cola, you get an empty bottle. You can exchange three empty bottles for one new bottle of cola. Calculate the maximum number of cola bottles you can drink.

**Input**: A positive integer N (N<200).

**Output**: The maximum number of cola bottles you can drink.

**Multiple test cases.**

## Input and Output Example

### Input Example #1

```
8
```

### Output Example #1

```
12
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
