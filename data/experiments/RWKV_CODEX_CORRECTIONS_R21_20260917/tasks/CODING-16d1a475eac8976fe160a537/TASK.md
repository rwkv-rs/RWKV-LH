You are given $T$ test cases. For each test case, you will be provided with a string $S$ where $1 \leq \lvert S \rvert \leq 10^5$. Your task is to find the number of unique substrings of length 3 (substrings do not need to be contiguous) and output the count.

## Input and Output Examples

### Input Example #1

```
5
PROGRAMMING
COLOMBIA
NUEVE
AAAAAAA
PQ
```

### Output Example #1

```
110
46
9
1
0
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
