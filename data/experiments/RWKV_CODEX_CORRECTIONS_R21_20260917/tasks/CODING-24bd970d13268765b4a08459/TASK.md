Given a sequence of numbers, determine the length of the longest increasing subsequence and output each element of this subsequence.

## Input and Output Examples

### Input Example #1

```
-7
10
9
2
3
8
8
6
```

### Output Example #1

```
4
-
-7
2
3
6
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
