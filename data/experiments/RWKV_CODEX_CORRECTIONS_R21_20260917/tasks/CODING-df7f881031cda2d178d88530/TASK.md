Given $n$, determine if it is possible to divide a regular hexagon into $n$ congruent parallelogram regions. If it is possible, output `1`; otherwise, output `0`.

## Input and Output Examples

### Input Example #1

```
2
147
```

### Output Example #1

```
0
1
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
