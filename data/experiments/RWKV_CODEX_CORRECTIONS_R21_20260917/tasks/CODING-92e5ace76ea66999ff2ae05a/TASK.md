Petr and Dmitry are researching a new data compression scheme. Their task is to compress a given set of words. To compress a given set of words, they must construct a rooted tree. Each edge of the tree contains a single letter. Let us define the dictionary generated by such a tree as a set of strings that can be read from any vertex in the tree (not necessarily from the root to a leaf and not necessarily ending at a leaf). Their task is to construct this tree using the dictionary, which is a set of words to be compressed. The tree should have the minimum number of vertices among trees that satisfy the above conditions. Any tree with an equal number of vertices is acceptable. Your task is to assist them.

![img](https://cdn.luogu.com.cn/upload/image_hosting/e3cj0ju9.png?x-oss-process=image/resize,m_lfit,h_170,w_225)

For example, in the tree with the root labeled as 1 in the figure above, the path from 7 to 5 reads "north," the path from 16 to 12 reads "eastern," the path from 29 to 2 reads "european," the path from 3 to 25 reads "regional," and from 1 to 31 reads "contest."

## Input Description

The input file contains several test cases, each as described below.

The first line contains the number of words `n` (1 ≤ n ≤ 50) in the given set. The following `n` lines contain different non-empty words, one word per line, composed of lowercase English letters. Each word's length does not exceed 10 characters.

## Output Description
The output should contain several test cases, each as described below.

In the first line, output the number of vertices `m` in the tree. The following `m` lines should describe the vertices of the tree, one description per line. The description method is as follows:

Vertices are indexed in order from 1 to n by their respective descriptions. If the corresponding vertex is the root of the tree, its description line should contain a single integer "0." Otherwise, its description line should contain its parent node and a single letter on its edge, separated by a space.

Note: This sample output corresponds to the picture in the problem statement.
