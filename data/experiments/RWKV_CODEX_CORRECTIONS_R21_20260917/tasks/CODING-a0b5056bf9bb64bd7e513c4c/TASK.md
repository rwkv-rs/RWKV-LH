If you ask a karaoke enthusiast, "Which songs are must-sing for you at KTV?" you'll often hear the answer includes a "legendary hit": Leo Ku's "Jin Ge Jin Qu." Why is that? Generally, KTV won't abruptly cut off a song when "time's up." Instead, it lets the song finish playing. For example: if you start singing a 2-minute song with only 15 seconds left, you effectively sing for an additional 105 seconds. However, the 11-minute and 18-second long "Jin Ge Jin Qu," which incorporates 37 songs, provides an extra 663 seconds of singing time!

Imagine you're at KTV with t seconds left. You've decided to sing only some of your favorite n songs (excluding "Jin Ge Jin Qu") before the session ends, and then finish with "Jin Ge Jin Qu," aiming to sing the most number of songs (including "Jin Ge Jin Qu") and leave KTV as late as possible.

Input n (n <= 50), t (t <= 10^9), and the length of each song (ensuring no song is longer than 3 minutes). Output the total number of songs sang and the total singing time. The input guarantees the total length of all n+1 songs is strictly greater than t.

## Input and Output Example

### Input Example #1

```
2
3 100
60 70 80
3 100
30 69 70
```

### Output Example #1

```
Case 1: 2 758
Case 2: 3 777
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
