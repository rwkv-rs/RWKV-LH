You are given multiple sequences of words. For each word, you need to reverse it (including punctuation), while maintaining the word's position in the sequence.

## Input Format

The input consists of multiple lines, each containing a sequence of words.

## Output Format

For each line, output each word in reverse order, without changing each word's position in the sequence.

## Input and Output Samples

### Input Sample #1

```
I love you.
You love me.
We're a happy family.
```

### Output Sample #1

```
I evol .uoy
uoY evol .em
er'eW a yppah .ylimaf
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
