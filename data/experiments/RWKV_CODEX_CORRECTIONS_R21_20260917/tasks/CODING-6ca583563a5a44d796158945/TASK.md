There are \( n \) jobs to be assigned to \( n \) individuals. The benefit generated by the \( i \)-th individual performing the \( j \)-th job is \( c_{ij} \). Design an assignment plan to assign \( n \) jobs to \( n \) individuals such that the total benefit is either minimized or maximized.

## Input Format

The first line of the input file contains a single positive integer \( n \), indicating that there are \( n \) jobs to be assigned to \( n \) individuals.

The next \( n \) lines each contain \( n \) integers \( c_{i,j} \), representing the benefit generated by the \( i \)-th individual performing the \( j \)-th job.

## Output Format

Output two lines: the first line should contain the minimum total benefit, and the second line should contain the maximum total benefit.

## Sample Input and Output

### Input Sample #1

```
5
2 2 2 1 2
2 3 1 2 4
2 0 1 1 1
2 3 4 3 3
3 2 1 2 1
```

### Output Sample #1

```
5
14
```

## Notes

\( 1 \leq n \leq 50 \), \( 0 \leq c_{i,j} \leq 100 \).

Each individual can only perform one job.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
