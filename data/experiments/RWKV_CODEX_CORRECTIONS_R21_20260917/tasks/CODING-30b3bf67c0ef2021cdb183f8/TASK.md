Each lottery ticket has a beautiful pattern, and there are a total of n different patterns. If you collect all n patterns, you can ~~summon the dragon~~ exchange them for a grand prize.

The question is, on average (under ideal conditions), how many lottery tickets do you need to buy to win the grand prize?

$n\leq33$

## Input and Output Example

### Input Example #1

```
2
5
17
```

### Output Example #1

```
3
   5
11 --
   12
   340463
58 ------
   720720
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
