Problem Summary:

John Doe wants to visit all destinations with the minimum total distance travelled. Each destination is represented by coordinates (xi, yi). No two destinations have the same xi. The distance between any two destinations is the straight-line distance between those two points. John travels as follows: he starts at the leftmost point, then can only move to the right until he reaches the rightmost point, after which he can only move to the left, returning to the starting point. Each point must be visited, and except for the starting point, each point can only be visited once.

Please write a program to calculate the minimum distance that satisfies these requirements.

(Input)

There are many groups of data. The first number in each group is the number of points in that group. Each subsequent line represents a point, with xi on the left and yi on the right. The points in these lines are given in ascending order of xi. There may be arbitrary spaces in the input. The input data is correct.

(Output)

The answer for each group should occupy one line, with the result rounded to two decimal places.

(Sample Input Explanation)

The first group has 3 points. The first point has xi as 1 and yi as 1. The second point has xi as 2 and yi as 3. The third point has xi as 3 and yi as 1.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
