There are two machines, $A$ and $B$, which have $n$ and $m$ modes respectively.

There are $k$ tasks. For each task $i$, two integers $a_i$ and $b_i$ are given, indicating the mode required if the task is executed on machine $A$ and machine $B$, respectively.

Initially, both machines start in mode 0 and do not consume time when powered on for the first time. Tasks can be executed in any order, but each mode change on a machine requires a restart. Determine how to assign tasks and arrange their order in such a way that the number of machine restarts is minimized.

$1 \leq n,m \leq 100$; $1 \leq k \leq 1000$; $0 \leq a_i < n$; $0 \leq b_i < m$.

There may be multiple test cases.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
