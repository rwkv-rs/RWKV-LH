## Problem Statement:

+ Given an $n \times m$ map, where ``L`` represents the starting point and ``#`` indicates the presence of a nut.
+ Find the shortest path to collect all the nuts, passing through each nut at most once, and finally returning to ``L``.

### Constraints
+ $n, m < 20.$
+ The number of nuts $\le 15.$

## Input and Output Example

### Input Example #1

```
5 5
L....
#....
#....
.....
#....
5 5
L....
#....
#....
.....
#....
```

### Output Example #1

```
8
8
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
