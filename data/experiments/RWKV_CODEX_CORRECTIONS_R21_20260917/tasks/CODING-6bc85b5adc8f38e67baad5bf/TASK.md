There are $T$ test cases.  
For each test case, you are given a positive integer $n$ and a binary string $S$.  
Determine the position of the first occurrence of string $S$ in the **fractional part** of the binary representation of $\sqrt{n}$.  
The digit immediately after the decimal point is considered position 0.

## Input and Output Example

### Input Example #1

```
2
2 101
1202 110011
```

### Output Example #1

```
2
58
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
