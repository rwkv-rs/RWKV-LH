##### Problem Description  
A secret organization in Hudonia loves finding strange numbers when Hudonia encounters troubles. This time, they are looking for numbers with the following property: when you move the last digit of such a number to the front, the resulting number is twice the original number. The secret organization calls these numbers double-trouble numbers.  
In base 10, 421052631578947368 is a double-trouble number.  
Now, Hudonia gives you n different p's, and you need to find the smallest double-trouble number in base p. For example, the smallest double-trouble number in base 10 is 052631578947368421.

##### Input Description 
There are n lines, each with a single integer p.

##### Output Description 
There are n lines, each outputting the smallest double-trouble number in base p in base 10. Separate the outputs for two consecutive numbers with a space.

##### Tip/Note 
p ≤ 200.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
