Given `n` quadratic functions \( S_i(x) = ax^2 + bx + c \)  \((1 \leq i \leq n)\),

Define \( F(x) = \max(S_i(x)) \) for \( 0 \leq x \leq 1000 \),

Find the minimum value of \( F(x) \).

You are provided with `T` sets of data.

Output the result rounded to four decimal places.

\(a \leq 100, \; |b| \leq 5000, \; |c| \leq 5000;\)  
\(T < 100,\) all input values are integers.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
