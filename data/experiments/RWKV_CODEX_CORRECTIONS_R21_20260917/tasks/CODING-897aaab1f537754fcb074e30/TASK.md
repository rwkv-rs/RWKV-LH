Given a positive integer $N$ ($1 \le N \le 10^7$), it is known that the minimum value of a triangular number equals $N$.

Triangular numbers are defined as follows:

$$ \sum_{i = 1}^{X}i = 1 + 2 + 3 + 4 + \dots + X$$

where $X$ is any positive integer.

**Input:**

Multiple test cases are provided.

Each test case is presented on a single line and contains a positive integer $N$.

The end of the test cases is indicated by EOF.

**Output:**

For each test case:

Output a single line containing a positive integer, representing the triangular number whose sum equals $N$.

## Input and Output Samples

### Input Sample #1

```
1
2
6
10
```

### Output Sample #1

```
1
2
1
1
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
