In a three-dimensional space, there are $n$ $(2 \leq n \leq 50)$ points moving at constant speeds. The initial coordinates of the $i$-th point are $(x,y,z)$, and its velocity is $(vx,vy,vz)$. Determine how many times the minimum spanning tree will change. The input guarantees that at any given moment, the minimum spanning tree is always unique, and each time it changes, the new minimum spanning tree will last for at least $10^{-6}$ units of time.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
