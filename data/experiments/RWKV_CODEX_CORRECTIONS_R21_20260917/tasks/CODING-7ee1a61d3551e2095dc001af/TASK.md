Translation: There is a grid cake with n rows and m columns (1 <= n, m <= 20) that has k cherries on it. You can slice the cake into two pieces with a single straight cut along the grid lines, but the cut can only be straight and cannot bend. The goal is for each final piece of cake to have exactly one cherry, and the total length of the cutting lines should be minimized.

### Input and Output Format
- **Input Format:** Each input contains multiple datasets. Each dataset begins with a line containing three positive integers n, m, k (rows, columns, number of cherries), followed by k lines, each containing two positive integers indicating the coordinates of the cherries.
- **Output Format:** Output several lines, each corresponding to a dataset. Each line should output two integers (id, minimal cutting length).

### Input and Output Example
- **Input Example:**
  ```
  3 4 3
  1 2
  2 3
  3 2
  ```
- **Output Example:**
  ```
  Case 1: 5
  ```
```

The input will be given via stdin and the output should be printed to stdout by your code.
