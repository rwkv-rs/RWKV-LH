A group of people wants to go to a restaurant. The restaurant's door size can be adjusted, but it can only be increased by one or decreased by one at each time interval. Each person has a fatness value, an arrival time, and a prosperity value. When a person arrives at the restaurant at their designated arrival time, if the restaurant's door size matches their size exactly, the restaurant obtains the current prosperity value. What is the maximum possible prosperity value?

## Input and Output Example

### Input Example #1

```
2
4 10 20
10 16 8 16
10 11 15 1
10 7 1 8
2 17 1000
5 0
50 33
6 1
```

### Output Example #1

```
26
0
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
