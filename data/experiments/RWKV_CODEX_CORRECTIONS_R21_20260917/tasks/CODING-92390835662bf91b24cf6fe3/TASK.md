Given an integer $n$, determine whether $\dfrac{1}{n}$ is a repeating decimal. If it is, output its decimal representation; otherwise, output its repeating cycle.

## Input and Output Example

### Input Example #1

```
2
101
757
```

### Output Example #1

```
0.0099
0.001321003963011889035667107
```

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
