### Problem Description

Given a circular area of length $n$, and $k$ regions that are already covered, determine the minimum number of additional regions needed to ensure the entire circle is fully covered.

### Input Format

The first line contains two integers, $n$ and $k$.  
The next $k$ lines each contain two integers representing a covered region.

### Output Format

If it is impossible to completely cover the circle, output `impossible`. Otherwise, output a single integer representing the minimum number of additional regions required.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
