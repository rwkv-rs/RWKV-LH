$B$ is a positive integer.

A natural number $n$ is called a B-smooth number if none of its prime factors exceed $B$.

A B-smooth number equivalent to $n$ is one that can be expressed as a product of positive integers less than or equal to $B$.

Your task is to find the number of B-smooth numbers within a given closed interval $[n, n+m]$.

## Input Format

The first line contains three integers $n$, $m$, and $B$.

## Output Format

Output the number of B-smooth numbers.

## Sample Input and Output

### Input Sample #1

```
30 10 5
```

### Output Sample #1

```
4
```

## Notes

For $100\%$ of the data, $1 \le n \le 2 \times 10^9$, $1 \le m \le 10^8$, $1 \le B \le 10^6$.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
