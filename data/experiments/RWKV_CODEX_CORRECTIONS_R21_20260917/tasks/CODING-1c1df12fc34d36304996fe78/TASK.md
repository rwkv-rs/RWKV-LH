Given a positive integer \( n \) (\( n \leq 400 \)) and \( k \) (\( k \leq 10 \)), find how many binary strings (strings containing only the characters 0 and 1) of length \( n \) do not contain any palindromic continuous substring of length at least \( k \). 

### Input
The first line contains a positive integer \( T \), the number of test cases (\( T \leq 400 \)). The following \( T \) lines each contain two positive integers \( n \) and \( k \), as described above.

### Output
For each test case, output the count of such binary strings modulo 1,000,000,007, followed by a newline.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
