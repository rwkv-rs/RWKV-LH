There is a grid composed of $n+1$ horizontal roads and $m+1$ vertical roads. Each horizontal road has a happiness value and a traversal time.

Now, $\mathsf{\color{black}{N}\color{red}{aCly\_Fish}}$ wants to walk from the bottom of the grid to the top, and she wants to know the maximum happiness value she can achieve.

For certain reasons, $\mathsf{\color{black}{N}\color{red}{aCly\_Fish}}$ will not traverse the same road multiple times, nor will she move from top to bottom. Additionally, the time spent on each horizontal road cannot exceed $k$.

$\mathsf{\color{black}{N}\color{red}{aCly\_Fish}}$ thinks this problem is too easy, so she asks you to find the solution for her.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
