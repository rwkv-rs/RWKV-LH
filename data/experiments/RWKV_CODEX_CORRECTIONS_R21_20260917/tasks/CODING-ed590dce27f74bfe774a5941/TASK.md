Given several line segment obstacles, determine if a monster can escape to infinity. The monster's initial coordinates are $(0,0)$.

The input consists of multiple datasets. Each dataset starts with an integer $n\ (1\leq n\leq100)$, representing the number of line segments. The following $n$ lines each contain four integers, which are the coordinates of the two endpoints of a line segment. The absolute value of any coordinate does not exceed $50$. It is assumed that two line segments can have at most one common point, and there are no cases where three lines intersect at a single point. The distance between any two intersection points is greater than $10^{-5}$. The input terminates with $n=0$.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
