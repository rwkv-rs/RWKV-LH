Little Petya likes integers. Recently, he has learned about different properties of sums of number's digits. For example, if the sum of a number's digits is divisible by 9, then the number itself is divisible by 9 as well.

Now, little Petya is interested in numbers with equal sum of digits. He asks his older brother Dima to find \( n \) positive integers with equal sum of digits and minimal possible total sum. Dima has other important things to do, so he asked you to write a program that solves this problem for him.

## Input Format

The input file contains a single integer \( n \) \( (1 \le n \le 5000) \).

## Output Format

Output the minimal possible sum of \( n \) positive integers, all having the same sum of digits.

## Sample Input and Output

### Sample Input #1

```
2
```

### Sample Output #1

```
11
```

### Sample Input #2

```
3
```

### Sample Output #2

```
33
```

## Notes

Time limit: 2 seconds, Memory limit: 256 MB.

The input will be given via stdin and the output should be printed to stdout by your code.

Now solve the problem by providing the code.
