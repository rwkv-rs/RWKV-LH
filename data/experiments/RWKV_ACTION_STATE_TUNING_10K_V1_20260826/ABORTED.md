# RWKV Action State Tuning 10K v1 中止记录

日期：2026-08-26（Asia/Shanghai）

## 结论

本实验已中止，未发布数据集，不得把本目录的预注册或生成器作为训练数据来源。

## 中止原因

旧方案把 20 个宽泛 seed 扩展为大量语义 family、实体命名空间和上下文组合。它可以
满足解析、去重、回放和表面相似度闸门，但样本数量主要来自模板组合，不是来自项目中
已经观测到的原始错误、错误状态及对应的正确状态迁移。这不满足 state tuning 的目的。

## 后续整改

替代版本必须先建立带来源摘要的 failure registry，并严格区分：

1. 只能由控制器、存储、恢复或资源生命周期修复的工程缺陷；
2. RWKV 可以通过状态传递与动作选择学习的模型缺陷；
3. 每个模型缺陷的真实错误动作、正确动作、状态差异与困难负例；
4. 不含冻结 holdout prompt、reference answer 或凭据的语义重建场景。

只有来源覆盖、状态迁移覆盖与困难负例覆盖达到预注册阈值后，才允许生成 10,000 条。
